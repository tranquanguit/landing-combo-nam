2. Cơ sở dữ liệu

PostgreSQL 17 (container db). Lược đồ db/pg/*.sql: đơn hàng, chống spam, nội dung, ảnh, tài khoản quản trị.

Bảng orders

CộtKiểuGhi chú
idINTEGERPRIMARY KEY AUTOINCREMENT
order_codeTEXTNOT NULL UNIQUE — dạng MC-260914-A7K3, khách đọc qua điện thoại
created_atTEXTNOT NULL — ISO 8601 UTC
Đơn đặt gì
product_slugTEXTNOT NULL — khớp thư mục src/content/products/<slug>
localeTEXTNOT NULL — vi | en | th | id
packTEXTNOT NULL — id gói khách chọn
pack_priceINTEGERVND tại thời điểm đặt; NULL = gói chỉ tư vấn
currencyTEXTNOT NULL DEFAULT 'VND'
Khách là ai — dữ liệu cá nhân
nameTEXTNOT NULL
phoneTEXTNOT NULL — đã chuẩn hoá 0xxxxxxxxx
addressTEXTNULL với gói chỉ tư vấn
countryTEXTdùng cho đơn ngoài Việt Nam
noteTEXTghi chú của khách
Bằng chứng đồng ý
data_consentINTEGERNOT NULL CHECK (data_consent = 1) — CSDL từ chối đơn không có đồng ý, kể cả khi mã nguồn lỗi
consent_textTEXTNOT NULL — đúng câu khách đã đọc lúc bấm
Nguồn — không phải dữ liệu cá nhân
utm_sourceTEXTĐọc từ URL lúc gửi đơn, không từ cookie. utm_content và utm_term thêm bởi migration 0002.
utm_mediumTEXT
utm_campaignTEXT
utm_contentTEXT
utm_termTEXT
referrer_hostTEXTchỉ tên miền, KHÔNG lưu URL đầy đủ
Vận hành
statusTEXTNOT NULL DEFAULT 'new' — CHECK IN (new, contacted, confirmed, shipped, done, cancelled)
staff_noteTEXTghi chú nội bộ
updated_atTEXTlần đổi trạng thái gần nhất

Index:

idx_orders_created  ON orders (created_at DESC)
idx_orders_status   ON orders (status, created_at DESC)
idx_orders_phone    ON orders (phone)

Bảng rate_limit

CộtKiểuGhi chú
keyTEXTPRIMARY KEY — IP đã băm SHA-256 + muối, cắt còn 16 ký tự
countINTEGERNOT NULL DEFAULT 1
window_atTEXTNOT NULL — mốc bắt đầu cửa sổ, tự hết hạn

KHÔNG lưu — cố ý

  • Địa chỉ IP thô — chỉ giữ bản băm để chống spam
  • User-Agent
  • Cookie quảng cáo
  • Mã khách hàng của bên thứ ba
  • Email khách — biểu mẫu không hỏi
Deploy: chạy npm run db:migrate TRƯỚC khi đẩy mã. Ngược lại sẽ có một khoảng mã mới gặp bảng cũ và mọi đơn hàng lỗi no column named utm_content. npm run db:migrate:status cho biết CSDL đang ở đâu.

3. Hai luồng dữ liệu

Nội dung → trang (lúc build, không có máy chủ)

src/content/*.json
      ↓  content.config.ts  — Zod kiểm; sai thì BUILD DỪNG
src/layouts/ + src/components/
      ↓  astro build
dist/  — 51 trang HTML tĩnh + sitemap + ảnh đã tối ưu
      ↓
Docker: app + db (+ caddy)

Khách đặt hàng (lúc chạy)

Biểu mẫu trong khối "order"
      ↓  fetch POST → PUBLIC_ORDER_ENDPOINT
functions/api/orders.ts
      ↓  kiểm dữ liệu · chống spam (IP băm) · gộp đơn trùng trong 2 phút
Postgres: orders + rate_limit + nội dung
      ↓  đọc qua ADMIN_TOKEN
/admin  — lọc, đổi trạng thái, xuất CSV

Chưa khai PUBLIC_ORDER_ENDPOINT thì trang không render thẻ <form>, chỉ hiện hotline.

4. Sửa gì ở đâu

Muốn đổiVào đâu
Chữ trên trang sản phẩmsrc/content/products/<slug>/vi.json (bản EN: en.json)
Thứ tự các phần trên trangmảng blocks[] trong chính tệp đó
Giátrường price. Chỗ khác nhắc bằng {{price}}; viết số tay → hỏng build
Trang dòng sản phẩmsrc/content/lines/<slug>/vi.json
Bài tư vấnsrc/content/articles/<slug>/vi.json — tối thiểu 350 từ
Chính sách, liên hệsrc/content/policies/ — mục chưa chốt để trong pending
Hotline, email, MST, địa chỉsrc/data/mocha.json — một nguồn duy nhất
Nhãn nút, chữ giao diệnsrc/i18n/ui.ts
Màu, cỡ chữ, nhịp giãn cáchsrc/styles/tokens.css
Ảnhbỏ tệp mới vào src/assets/images/, giữ nguyên tên cũ
Tên miền.env trên máy chủ; mặc định ở astro.config.mjs, public/robots.txt

Trong JSON luôn viết đường dẫn ảnh dạng /images/ten.webp — build tự ánh xạ sang tệp trong src/assets/. Sai tên thì build dừng.

Chữ in trong ảnh cũng là nội dung. Hàng rào claims không đọc được chữ nằm trong ảnh — một lời hứa bị cấm đặt trong ảnh vẫn lên trang được. Phải tự soát.
